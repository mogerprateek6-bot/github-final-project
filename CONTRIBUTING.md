# Contributing

Thank you for considering a contribution!

## How to contribute

1. Check existing issues and pull requests before starting work.
2. Open an issue to discuss a substantial change.
3. Fork the repository and create a branch for your change.
4. Make a focused change and test it locally.
5. Commit your work with a clear message.
6. Open a pull request describing what changed and why.

## Reporting bugs

Include the steps to reproduce the problem, the expected result, the actual result, and relevant terminal output.

## Suggesting improvements

Explain the problem your suggestion solves and provide an example where possible.

## Bash script checks

Before submitting changes to `simple-interest.sh`, run it with sample inputs and check that the result is correct. Keep prompts clear and handle invalid numeric input where practical.

## Communication

Please follow the project's [Code of Conduct](CODE_OF_CONDUCT.md).
