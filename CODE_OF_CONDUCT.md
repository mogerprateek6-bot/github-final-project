# Code of Conduct

## Our commitment

Everyone participating in this project is expected to help make collaboration respectful, welcoming, and constructive.

## Expected behavior

- Be respectful and considerate.
- Welcome questions and constructive feedback.
- Focus criticism on ideas and work, not people.
- Respect different experiences and perspectives.
- Help keep discussions relevant and useful.

## Unacceptable behavior

Harassment, insults, discriminatory language, intimidation, and repeated disruptive behavior are not acceptable.

## Reporting concerns

If you experience or observe unacceptable behavior, contact the project maintainer privately through the contact method listed in the repository profile. Reports will be reviewed respectfully and handled as confidentially as possible.

## Scope

This code of conduct applies to project spaces, including issues, pull requests, and other project-related discussions.
